# Controle de Acesso - Web Angular

Aplicacao web do sistema de controle de acesso biometrico escolar.

## Areas previstas

- `/admin`: painel administrativo
- `/responsavel`: portal do responsavel
- `/terminal`: interface web/PWA do terminal no MVP

## Stack

- Angular
- TypeScript
- SCSS

## Setup local

1. Instale dependencias:

```bash
npm install
```

2. Suba o frontend:

```bash
ng serve
```

URL local padrao:

```txt
http://localhost:4200
```

## API

A aplicacao deve consumir a API Laravel do repositorio `controle-acesso-api-laravel`.

URL local esperada:

```txt
http://localhost:8000/api
```
